# 声光

把平板的音量和亮度调得更细。不需要 root，不联网，不替换桌面或系统界面。

- **音量**：0–100 级细调（系统档位加一层数字增益），音量键防抖或接管。
  扬声器、有线耳机、USB、蓝牙各自一条曲线，各自记住上次的音量；换输出时先清掉增益再恢复。
  蓝牙由耳机自己调音量、送出的是满幅信号，所以细调只往下压，不往上补，避免削顶。
- **亮度**：一个滑块连续调亮度和系统「极暗」，带三个预设。
- **入口**：快捷设置磁贴打开小面板；下拉通知栏时在旁边显示音量和亮度滑块（可在面板里关掉）。
- **更新**：面板里显示当前版本，「下载最新版」用浏览器下载最新安装包，点开即可覆盖安装。应用本身没有联网权限。

在酷比魔方掌玩 mini2（Android 14）的扬声器上验证过；蓝牙的曲线按系统给的数据估计，还没实机验证。

## 授权

装好后在面板里批准「修改系统设置」，再用电脑执行一次：

```
adb shell pm grant io.github.shengguang android.permission.WRITE_SECURE_SETTINGS
```

之后在面板里点「一键开启」打开无障碍服务（酷比的无障碍设置页不列出第三方服务，没法手动开）。
以后覆盖安装新版本，之前开着的服务会自动重新打开。不要先卸载，卸载会让上面的授权失效。

无障碍服务只处理音量加减两个键，并接收系统界面的窗口变化来判断下拉面板是否打开，不读取屏幕内容。

## 编译

每个分支推送都会由 GitHub Actions 编译并跑单元测试，分支上的安装包在该次运行的 Artifacts 里。
推送到 main 才会发布 Release，面板里的「下载最新版」指向最新的 Release。
需要两个仓库 Secret：`SIGN_KEYSTORE_B64`（keystore 的 base64）和 `SIGN_PASSWORD`。
